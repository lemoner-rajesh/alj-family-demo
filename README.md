# alj-family-demo

Interactive family tree prototype for The Jameel Family — a React + Vite demo.

All data is mock/local (`src/data/familyData.js`); there is no backend. The landing page (`/`) offers a tree/timeline toggle, search, legend, and stats — click any card for details, click a branch's toggle to expand or collapse it.

## Running locally

```bash
npm install
npm run dev
```

```bash
npm run build   # production build
npm run lint    # oxlint
```
